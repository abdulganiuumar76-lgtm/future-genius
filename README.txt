FUTURE GENIUS — PROTOTYPE

Contents:
- index.html: responsive learning app
- manifest.json: installable web app metadata
- sw.js: offline caching

Features in this prototype:
- Blue-and-white modern dashboard
- Course cards and lesson pages
- Starter notes for Maths, Physics, Biology, Chemistry, English, Python and Robotics/AI
- Multiple-choice quiz with automatic marking and explanations
- Local progress tracking and profile page
- Search and basic offline cache

Limitations:
This is a working web-app prototype, not a native Android APK. To use install/offline features, host it on HTTPS and open it once online in a supported browser. Online content and account sync are not implemented yet. Built-in notes and questions are starter examples, not a complete JAMB question bank.
